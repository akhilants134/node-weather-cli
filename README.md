# node-weather-cli

# Weather CLI Application

This application fetches weather data for a specified city using a public weather API.

## Features

- Fetch weather data based on city name from command-line arguments.
- Asynchronous HTTP requests to a weather API.
- Error handling for API responses.

## Setup

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Use `node index.js <city_name>` to get the weather data.

## API Used

- OpenWeatherMap API (https://openweathermap.org/api)
